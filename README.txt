FAMILY MTB TOUR PAGES PACKAGE

This archive contains the Family MTB listing with detail links, the shared FamilyTripDetail page component, and ten static tour routes.

Extract from the existing project root (beside package.json):
  unzip -o ./family-mtb-tour-pages-package.zip -d .

Only these paths are included:
- src/app/cycling-trips/family-mtb/page.tsx
- src/components/trips/FamilyTripDetail.tsx
- ten src/app/cycling-trips/trip/<named-duration-slug>/page.tsx routes

No globals.css, homepage, header or footer files are included. Suggested itineraries are outline concepts and should be confirmed before sale.
